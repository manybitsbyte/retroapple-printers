**  SCREEN TO PRINT - IMAGEWRITER IIThese programs dump the Apple //egraphics screen to an ImageWriter IIover the Super Serial Card in slot 2.Color or black-and-white.FILES IN THIS FOLDER--------------------LORES.PLOT   draw 40-col lo-res testLORES.BW     print lo-res  (black)LORES.COLOR  print lo-res  (color)DLORES.PLOT  draw 80-col dbl lo-resDLORES.BW    print dbl lo-res (black)DLORES.COLOR print dbl lo-res (color)HGR.ART      draw hi-res test pictureHGR.BW       print hi-res  (greys)HGR.COLOR    print hi-res  (color)DHGR.ART     draw dbl hi-res pictureDHGR.COLOR   print dbl hi-res (color)DHGR.BW      print dbl hi-res (greys)VIEW         show this READMESET UP------1. Super Serial Card in slot 2.2. ImageWriter II on-line.3. Color ribbon + COLOR mode for the   color programs.PAGE SELECT (location 9)------------------------POKE 9,0  = graphics page 1POKE 9,1  = graphics page 2DRAW THEN PRINT--------------Run a PLOT to draw a screen then runthe matching print program to dump it.Lo-res page 1 example:] BLOAD LORES.PLOT,A$6000] POKE 9,0 : CALL 24576] BLOAD LORES.COLOR,A$6000] CALL 24576Double lo-res page 1 example:] BLOAD DLORES.PLOT,A$6000] POKE 9,0 : CALL 24576] BLOAD DLORES.COLOR,A$6000] CALL 24576Hi-res page 1 example:] BLOAD HGR.ART,A$6000] CALL 24576] BLOAD HGR.COLOR,A$6000] CALL 24576Double hi-res page 1 example:] BLOAD DHGR.ART,A$6000] CALL 24576] BLOAD DHGR.COLOR,A$6000] CALL 24576HGR/DHGR CONTROLS (before CALL)-------------------------------The HGR/DHGR dumps add their ownknobs in place of POKE 9:POKE 24579,n  width 0=7.8" 1=7.0"              2=5.8" 3=3.5" (4:3)POKE 24580,1  double height (tall)POKE 24581,p  page 0=one 1=twoPOKE 24582,s  serial slot (def 2)NOTES-----Code is relocatable - any A$addr OK.Dbl lo-res shows on screen only frompage 1.  A dump can take a minute asthe printer paces the output.BW programs also suit an ImageWriter I.Happy printing!
